# MVC5-Demo

## About

This project is built with **ASP.NET Web Application (.NET Framework)**, which is an older version compared to ASP.NET Core Web App (Razor Pages). 

Because of this, the code in `.cshtml` files cannot use modern tag helpers like `@asp-for` or `@asp-controller`. In the C# code, you also cannot use newer features like nullable reference types (`nullable? null!`). You will find out more differences as you code yourself.

- **Version:** .NET Framework 4.7.2
- **Structure:** 3-Layer Architecture (App / Service / Repository) with Dependency Injection.
- **Database:** Pre-created local DB using Microsoft SQL Server + C# Models generated by ADO.NET Entity Data Model.

## Packages

### MVC Layer
- `Entity Framework 6`
- `Unity.Mvc5` *(For Dependency Injection in MVC)*

### Service Layer
- `Mapster` *(For mapping models)*

### Repository Layer
- `Entity Framework 6`

1. Download this source code.
2. Open `ExampleMVC\ExampleMVC.slnx` with Visual Studio.
3. Right-click on the **Solution** in Solution Explorer and choose **"Restore NuGet Packages"**.
4. Click on **"Run Debug"** (`F5`) or find it on the top menu tray (**Debug** -> **Start Debugging**).

## Code Guide

### 1. Project Setup
- Create a new project: **ASP.NET Web Application (.NET Framework)**.
- Create the 3-Layer structure:
  1. Right-click **Solution** -> Choose **Add** -> **New Project...**
  2. Choose **Class Library (.NET Framework)**.
  3. Name the layer and repeat this for the other layers.

### 2. Add Project References
Follow this order: `App -> Service -> Repository`
1. Right-click on the **Project Name**.
2. Choose **Add** -> **Reference...**
3. In the "Reference Manager" window, open the **Projects** tab.
4. Tick the project that your current project will reference.
5. Repeat for other projects (layers).

### 3. Install Packages & Structure Setup
- Install the packages described in the [Packages](#packages) section above.
- **Dependency Injection (DI):** You have to use interface classes instead of direct classes. Create folders and files following the structural example.

### 4. Database & Models
- Create models in C# if you are doing *Code-First*, or create them in SQL Server and then scaffold them to C#.
- The guide below is for *Database-First* (using the ADO.NET tool to scaffold):
  - Right-click the **Models** folder -> **Add** -> **New Item...**
  - Choose **Data** -> **ADO.NET Entity Data Model** -> **Code First from database**.

### 5. Configurations

**Update `App/Global.asax`:**
Add the Unity component registration line:
```csharp
AreaRegistration.RegisterAllAreas();
UnityConfig.RegisterComponents();      // <-- Add this line
FilterConfig.RegisterGlobalFilters(GlobalFilters.Filters);
```

**Update `App/App_Start/UnityConfig.cs`:**
This is where you register the scope for your DI classes:
```csharp
public static void RegisterComponents()
{
    var container = new UnityContainer();

    // Register all your components with the container here
    // It is NOT necessary to register your controllers
    // e.g. container.RegisterType<ITestService, TestService>();
    
    DependencyResolver.SetResolver(new UnityDependencyResolver(container));
}
```

**Update `App/App_Start/BundleConfig.cs`:**
Use the bundle for full Bootstrap JS features:
```csharp
// Replace default with bootstrap.bundle.js
bundles.Add(new Bundle("~/bundles/bootstrap").Include(
          "~/Scripts/bootstrap.bundle.js"));
```

### 6. Controllers and Views Logic
Now build the Controller's methods and Views. Views connect to the controller and execute C# logic using the `@` syntax.

In the controller, one action method usually returns a view (meaning it renders a UI page, but doesn't actually handle your submitted data). The right steps to code this workflow are:

1. Create a method in the controller to render the page (Navigation method / `[HttpGet]`).
2. Create a method with the same name in the controller to actually receive data and handle CRUD logic, marked with `[HttpPost]`.
3. In the View, when you need to send data to the controller, use `<form action="nameAction" method="post">` or `@Html.BeginForm(...)`.
